# Бот-админ для Telegram-чата

Модерация (баны, муты, варны), экономика и работы, панель владельца, профили с никами/ролями, приветствия, добровольные упоминания и мини-игры на виртуальные монеты. Python 3.10+, aiogram 3, SQLite.

## Что умеет

**Модерация** (только для админов чата; ответом на сообщение или `@ник` / ID):

| Команда | Что делает |
|---|---|
| `/бан [время] [причина]` | бан, без времени навсегда |
| `/разбан` | снять бан |
| `/кик` | выгнать (можно вернуться) |
| `/мут [время] [причина]` | запретить писать, без времени 1 час |
| `/размут` | снять мут |
| `/варн [причина]` | предупреждение, 3 варна = мут на 24 ч |
| `/снятьварн` | убрать один варн |
| `/варны` | сколько варнов |
| `/удалить` | удалить сообщение (ответом) |
| `/чистка` | удалить всё от выбранного сообщения до команды (до 100) |
| `/закрепить`, `/открепить` | закреп (ответом) |

Время: `30м`, `2ч`, `1д`, `1н` или `навсегда`. Админов чата и владельца наказать нельзя.

**Монеты и работа** (для всех):

| Команда | Что делает |
|---|---|
| `/работа` | выйти на смену и получить монеты |
| `/работы` | список работ, выбрать работу кнопкой |
| `/уволиться` | уйти с работы |
| `/профиль` | баланс, работа, прогресс |
| `/баланс` | баланс (свой или чужой) |
| `/передать [@ник] сумма` | перевести монеты |
| `/топ` | самые богатые |

**Владелец бота:** `/панель` — панель владельца; `/юзер ID` или ответ `/юзер` — редактор профиля; `/выдать [@ник] сумма` и `/забрать [@ник] сумма` (можно писать `5к` = 5000). В редакторе можно менять баланс, ник, роль, работу, смены, общий заработок и число варнов в текущем чате. Команды владельца не выводятся в общей справке.

**Дополнительно:** `/приветствие текст` — настроить приветствие группы; переменные `{name}`, `{username}`, `{id}`. `/приветствие выкл` — отключить. `/зов_вкл` и `/зов_выкл` — согласие/отказ от упоминаний; `/зов` упоминает только подписавшихся участников, не чаще раза в минуту и до 20 участников.\n\n**Мини-игры на виртуальные монеты:** `/слоты сумма`, `/кости сумма`, `/рулетка сумма красное|чёрное|зелёное`. Денежные ставки, пополнение и вывод не поддерживаются.\n\nВсе команды работают и латиницей: `/ban /mute /warn /work /jobs /balance /pay /slots /dice /roulette ...`

### Как устроены работы

В `jobs.py` 16 работ: от курьера (20–40 монет за смену) до космонавта (1400–2000). На первые две можно
устроиться сразу, на остальные нужно отработать определённое число смен в сумме (5, 12, 25, 40, 60, 90, 140, 200).
У каждой работы свой отдых между сменами, а ещё есть шанс 8% на премию ×1.5.
Свои работы добавляются одной строкой в список `JOBS`.

## Новые возможности\n\nПосле обновления таблицы `users` автоматически дополняются полями `custom_nick` и `role`, создаются таблицы настроек чатов и согласий на упоминания. Существующая база и балансы сохраняются.\n\n## Настройка

1. Создай бота в [@BotFather](https://t.me/BotFather), получи токен.
2. В BotFather: `/setprivacy` → выбери бота → `Disable` (чтобы бот видел русские команды вида `/работа`).
3. Добавь бота в чат и сделай его **администратором** (права: удалять сообщения, банить пользователей, закреплять сообщения).
4. Узнай свой ID: напиши боту `/id`.
5. Задай переменные (в панели хостинга или в файле `.env`, пример в `.env.example`):
   - `BOT_TOKEN` — токен бота
   - `OWNER_ID` — твой Telegram ID

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

### На BotHost

Загрузи файлы проекта (или подключи этот репозиторий), в переменных окружения укажи `BOT_TOKEN` и `OWNER_ID`,
команда запуска: `python bot.py`. База хранится в файле `bot.db`, делай её копию перед переездом.

## Заметки

- Команды владельца нужно отправлять не анонимно (от своего имени), иначе Telegram скрывает, кто пишет.
- По `@нику` бот находит только тех, кто хоть раз писал в чате при работающем боте. Ответом на сообщение работает всегда.
- Для `/мут` и `/чистка` нужна супергруппа (обычные группы Telegram не поддерживают ограничения).
