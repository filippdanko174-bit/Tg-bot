# ByFilipp — Telegram-бот для чатов

Модерация, игровая экономика, работы, магазин, роли, приветствия, панель владельца и мини-развлечения. Python 3.10+, aiogram 3, SQLite.

## Команды

### Утилиты и развлечения
| Команда | Действие |
|---|---|
| `/пинг` | Проверить ответ Telegram API |
| `/монетка` | Подбросить монетку |
| `/кости` | Бросить виртуальный кубик Telegram |
| `/число 1 100` | Случайное число в заданном диапазоне |
| `/завоз`, `/вайб`, `/рофл` | Шуточные команды |
| `/id` | ID пользователя и чата |
| `/help` | Полная справка |

Для команды `/число` нужны две целые границы; допустимый диапазон — от -1 000 000 до 1 000 000.

### Экономика
- `/работа`, `/работы`, `/уволиться` — смены и выбор работы.
- `/профиль`, `/баланс`, `/топ` — профиль, монеты и рейтинг.
- `/передать @ник сумма` — перевод монет.
- `/магазин`, `/инвентарь`, `/титул` — покупки и титулы.

### Модерация (администраторы группы)
- `/бан`, `/разбан`, `/кик` — управление участниками.
- `/мут`, `/размут` — ограничение сообщений.
- `/варн`, `/снятьварн`, `/варны` — предупреждения.
- `/удалить`, `/чистка`, `/закрепить`, `/открепить` — управление сообщениями.

Время наказания: `30м`, `2ч`, `1д`, `1н` или `навсегда`. Для модерации боту нужны соответствующие права администратора.

### Владелец
- `/панель` — интерактивная панель.
- `/юзер ID` — редактор профиля.
- `/выдать`, `/забрать` — управление игровым балансом.
- Настройка ролей и приветствий.

### Дополнительные функции
- `/зов_вкл` и `/зов_выкл` — добровольная подписка на упоминания.
- `/зов` — упоминает только согласившихся участников с ограничением частоты.

Русские команды работают в сообщениях. Для меню Telegram добавлены английские алиасы: `/ping`, `/coin`, `/dice`, `/number`, `/work`, `/profile` и другие.

## Установка

1. Создай бота через [@BotFather](https://t.me/BotFather).
2. Отключи privacy через `/setprivacy`, если бот должен читать команды в группах.
3. Добавь бота в группу и выдай необходимые права.
4. Установи зависимости: `pip install -r requirements.txt`.
5. Укажи переменные окружения `BOT_TOKEN` и `OWNER_ID`.
6. Запусти: `python bot.py`.

На BotHost укажи команду запуска `python bot.py`. Для сохранения базы между перезапусками настрой постоянный диск и `DB_PATH`.

## Безопасность и данные

- Не публикуй `BOT_TOKEN` и не отправляй его в чаты.
- Файлы `.env` и `bot.db` должны оставаться вне Git.
- SQLite-миграции выполняются автоматически; существующие балансы и профили сохраняются.
- Перед переносом или обновлением хранилища сделай резервную копию базы.

## Проверки

GitHub Actions проверяет синтаксис Python, импорты и тесты базы данных. Это автоматические проверки кода, а не полноценная проверка каждой команды в реальном Telegram.
